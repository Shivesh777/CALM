# Research code

Run everything from this folder (`cd experiments`); the scripts use paths relative to it.

## Pipeline

1. **Pools of forecasters** (`tsr/`). `python -m tsr.run --jobs jobs/<file>.jsonl --out <dir> --data-root data` trains
   the backbone (`tsr/train.py`) and runs the online test stream (`tsr/online.py`) with a pool of adaptation strategies:
   the frozen model, fine-tuning, closed-form output-layer and linear refits (recursive least squares, with or without
   forgetting), error-feedback correctors, seasonal naive forecasts, and external experts whose forecasts were dumped by
   the published code (`"kind": "external"`). Losses are used only after the whole target window has been observed.
   With `"dump_stats": true` every run stores, for every origin, the losses at each bucket's representative horizon and
   the Gram matrices of the experts' errors, from which any convex combination can be scored exactly.
   * `make_jobs.py`, `make_pre7.py` (Proceed protocol, iTransformer), `make_pre8.py` (DynaME protocol),
     `make_pre9.py` (PatchTST) generate the job files in `jobs/` and the baseline scripts in `pre/`.
2. **Published baselines**: `../scripts/get_baselines.sh`, then the commands in `pre/*.sh` (GD and Proceed with the
   released hyper-parameters; `DUMP_PREDS` makes them write their forecasts).
3. **Exact replay** (`replay.py`, `replay2.py`, `ablate.py`). `python ablate.py "<dir>/stats/*.npz" out.json` replays
   the aggregation rules of the paper and further exploratory variants (definitions in `ablate.py`; CALM is `meta5_eg_boa`, CALM-sel
   `meta3`, EW `naive_slow`, calibrated BOA `boa_grad_cal`, AdaHedgeD/DORM+/DUB `adahedged`/`dormp`/`dub`, the rule of
   Kim et al. `kim26`, ELF-w `elf_w`). The tuning-free delayed learners are re-implemented exactly in
   `replay2.replay_poold`.
4. **Analysis and tables.** `full_compare.py` (75 development settings), `confirm.py` / `confirm2.py` (the two
   pre-registered confirmatory rounds; the run directories are listed in `results/stats/r1_dirs.txt` and
   `r2_dirs.txt`), `dm_deep.py` / `dm_table.py` (Diebold-Mariano tests with the least favourable Bartlett bandwidth),
   `bucket_compare.py` (gap by horizon), `kappa_diag.py` (overlap factor), `cost_table.py` (per-step cost), and the
   `paper_tab_*.py` scripts, which write `tables/*.tex` (`../scripts/build_tables.sh` runs them all).
5. **Finance** (`fin_*.py`, `finance_data/`). Panel construction (`finance_data/`), online runs (`fin_run.py`),
   replays (`fin_*_replay*.py`), QLIKE / model confidence set / volatility targeting (`fin_qlike.py`, `fin_eval.py`) and
   the VWAP study (`fin_vwap_*.py`).
6. **Simulations** (`sims/`): the overlap simulations behind Figure 2 and the numerical checks of Appendix A.

## Results

`results/raw/<run>/` holds the outputs of every run (metrics, replays, Diebold-Mariano statistics) and `results/stats/`
the merged summaries. Run directories are named after the job: `base7*` Proceed protocol with published methods in the
pool (iTransformer), `base8*` DynaME protocol, `base9*` PatchTST, `lin*` RLinear, `online4` the iTransformer
development pool; prefixes such as `dl-`, `kx-`, `pd-`, `pdx-`, `pm-` and `rpl-` mark batches run on different machines and
replays of further rules on the stored statistics. The per-origin
statistics (`*.stats.npz`, about 18 GB) are not included; they are regenerated by the runs.
